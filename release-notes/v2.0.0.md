# Console Language 2.0.0

The Language Hack is now **Console Language**, and it has been split in two: this add-on keeps the languages and the rōmaji titles, and the game translation patches have moved to their own add-on, **Game Translations** (`om_game-translations`).

It is rebuilt as an Options Menu add-on: pick a language and the menu reloads with it applied, no reboot, and more languages download from the console itself.

## Requirements

- [Options Menu v2.1.0](https://github.com/DefKorns/OptionsMenu/releases) or newer.
- Font Remount mod (`font_remount`), one of hakchi's built-in mods. It provides the title font, so install it to see accented letters and the rōmaji titles. Console Language no longer ships its own `title.fnt`.
- To download more languages from the console: the Hakchi Wi-Fi mod and a USB Wi-Fi adapter.

## What's new

### Languages

- Console Language is listed under **Language** in the Options Menu.
- Applying or reverting a language reloads the menu with a loading bar instead of rebooting the console.
- Famicom Shonen Jump, Famicom Mini and Super Famicom Mini: the hidden English, German, Spanish, French, Italian, Dutch, Portuguese and Russian are available from the menu. **Revert to Japanese** only shows when a language is applied.
- SNES (USA/EUR): the downloaded languages show up in the console's own Languages screen, after the eight stock ones. The list scrolls and wraps, the choice is remembered across reboots, and the Options Menu keeps the download and the delete. A firmware whose language script isn't one this release knows falls back to choosing from the Options Menu.
- NES (USA/EUR): custom languages replace the console's languages, and **Restore the original languages** puts them back.
- Each language shows its flag and a preview. Accented and Cyrillic glyphs are added to the stock fonts, which otherwise crash the UI (C8).
- Each firmware keeps its own language, so multi-booting needs no `.hsqs`.
- The Options Menu follows the console language while one is applied.

### Download more languages

- **Download more languages** lists the catalog for your console: Bahasa Indonesia, Spurdo, Português (Brasil), Svenska, Norsk, Ellinika and 日本語 (NES and SNES only).
- **Download all** fetches every language you don't have yet, with a progress bar and the free space left.
- Downloading a language you already have asks before replacing it. A language that is in use is replaced the next time the languages are bound.
- Hold **B** on an installed language to delete it, after a confirmation. The language in use can't be deleted.
- The catalog is cached for a day, and the cached copy is used when the console is offline.
- Every language is also a separate hmod per console, `om_console-language_<system>_<code>`, from the [language packs](https://github.com/DefKorns/om_console-language-packs/releases/tag/languages-v1), and in the hakchi-repo *Language Packs* tab. The Famicom Mini's languages come with this add-on.

### Rōmaji titles

On the Japanese systems, **Rōmaji titles** shows the games' names in rōmaji instead of kana and kanji. It no longer depends on the applied language, and it reloads the menu instead of rebooting.

### Under the hood

- The boot script is installed only while a language or the rōmaji titles are on, so a console without them boots exactly as before.
- Languages and fonts are bound per file, so Theme Selector keeps the applied language when it changes the theme.
- Errors show a message on screen and give control back to the menu.

## Coming from the Language Hack?

- **Install over it.** It uninstalls the Language Hack, Shonen Jump Language Hack and the older Options Menu language releases (RC4, b135 and b136), and restores the files they changed.
- Your applied language and your downloaded languages are kept.
- **Game translation patches are no longer part of this add-on.** The patches that the Language Hack applied are not carried over, and the Patches menu is gone. They return with Game Translations.
- The IPS patches and their credits live in `om_game-translations`, so Console Language is now small enough to be installed alone, and its title font comes from Font Remount.
